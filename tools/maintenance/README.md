# Scripts de Manutenção

Esta pasta contém scripts úteis para manutenção do projeto.

## Scripts Disponíveis

### `remove_hotmart_references.py`

**Objetivo**: Remove referências à Hotmart e outras redes não suportadas dos arquivos de documentação.

**Uso**:
```bash
python tools/maintenance/remove_hotmart_references.py
```

**Nota**: Este script foi usado durante a remoção da integração com a Hotmart e pode ser usado como referência para remoções semelhantes no futuro.
