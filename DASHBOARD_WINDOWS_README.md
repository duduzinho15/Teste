# 🎮 Dashboard Windows - Garimpeiro Geek

## 📋 Descrição

Dashboard nativo para Windows do sistema **Garimpeiro Geek** - Sistema de Recomendações de Ofertas. Interface completa e intuitiva para controle de todos os sistemas implementados.

## 🚀 Como Iniciar

### Opção 1: Script PowerShell (Recomendado)
```powershell
powershell -ExecutionPolicy Bypass -File start_dashboard.ps1
```

### Opção 2: Script Batch
```cmd
start_dashboard.bat
```

### Opção 3: Python Direto
```cmd
python windows_dashboard.py
```

## 🖥️ Características do Aplicativo

- **Tamanho**: 1200x800 pixels (mínimo: 800x600)
